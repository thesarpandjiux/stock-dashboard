# Swing 1–3 Hari Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Membangun mode long-only 1–3 hari yang memilih kandidat dari daily bars, mengonfirmasi entry lewat H1 pertama, menerapkan posisi $20–$50 dan risiko maksimal $0,50, lalu hanya masuk produksi setelah backtest walk-forward dan holdout lolos.

**Architecture:** Python menjadi satu-satunya mesin keputusan. Modul baru `swing_3d.py` menerima data daily/H1 yang sudah tersedia pada waktu keputusan dan menghasilkan status `CANDIDATE`, `READY`, `WAIT`, atau `REJECT`; modul `backtest_3d.py` memakai fungsi yang sama agar riset dan produksi tidak menyimpang. Pipeline dibagi menjadi daily candidate dan H1 confirmation, sementara JavaScript hanya merender kontrak `data.json`.

**Tech Stack:** Python 3.11 stdlib, pandas, yfinance, unittest, Node.js built-in test runner, GitHub Actions, HTML/CSS/vanilla JavaScript.

## Global Constraints

- Long-only; tidak ada short, options, leverage, margin, atau auto-order.
- Hold maksimal tiga hari bursa; posisi ditutup paling lambat sebelum close hari ke-3.
- Modal `$1.000`; fractional shares tersedia.
- Nilai posisi `$20–$50`; risiko maksimal `$0,50` atau `0,05%` modal per trade.
- Stop ditentukan dari struktur/ATR lebih dulu dan tidak boleh dipersempit agar setup lolos.
- Daily menghasilkan kandidat; `READY` hanya boleh muncul setelah candle H1 pertama selesai.
- Earnings unknown, data stale, atau H1 belum lengkap tidak boleh menghasilkan `READY`.
- Akurasi tidak boleh diklaim sebelum backtest, walk-forward, untouched holdout, dan paper run selesai.
- Existing `swing.py` 1–4 minggu tetap utuh selama pembangunan.
- Python menjadi satu-satunya sumber verdict; fallback verdict JavaScript dihapus setelah kontrak baru aktif.
- GitHub Actions menjadi satu-satunya writer produksi untuk `data.json`; cron lokal tidak boleh menulis paralel.
- Semua perubahan memakai TDD dan commit kecil.

```python
# swing_3d.py
ACCOUNT_CAPITAL = 1000.0
RISK_BUDGET = 0.50
MIN_POSITION = 20.0
MAX_POSITION = 50.0
VALID_STATUSES = {"CANDIDATE", "READY", "WAIT", "REJECT"}

def position_plan(entry, stop, capital=ACCOUNT_CAPITAL, risk_budget=RISK_BUDGET,
                  min_value=MIN_POSITION, max_value=MAX_POSITION):
    entry, stop = float(entry), float(stop)
    if entry <= 0 or stop <= 0 or stop >= entry:
        return {"eligible": False, "reason": "INVALID_LEVELS", "entry": entry, "stop": stop}
    risk_per_share = entry - stop
    shares = min(risk_budget / risk_per_share, max_value / entry)
    value = shares * entry
    risk = shares * risk_per_share
    return {
        "eligible": value + 1e-9 >= min_value,
        "reason": None if value + 1e-9 >= min_value else "POSITION_BELOW_MIN",
        "entry": entry, "stop": stop, "shares": round(shares, 6),
        "position_value": round(value, 2), "risk_dollars": round(risk, 2),
        "risk_pct_account": round(risk / capital * 100, 4),
    }

def reject(reason, phase, asof=None):
    return {"status": "REJECT", "phase": phase, "entry": None, "stop": None,
            "target": None, "shares": None, "position_value": None,
            "risk_dollars": None, "risk_pct_account": None,
            "reasons": [], "blockers": [reason], "asof": asof}
```

```python
RESEARCH_MIN_DOLLAR_VOLUME = 20_000_000
RESEARCH_MAX_EXTENSION_ATR = 2.0

def evaluate_daily(f, earnings_verified, earnings_in_trading_days, data_fresh):
    if not data_fresh:
        return reject("STALE_DAILY_DATA", "DAILY")
    if f.get("bars", 0) < 60:
        return reject("INSUFFICIENT_DAILY_BARS", "DAILY")
    if not earnings_verified:
        out = reject("EARNINGS_UNVERIFIED", "DAILY")
        out["status"] = "WAIT"
        return out
    if earnings_in_trading_days is not None and earnings_in_trading_days <= 3:
        return reject("EARNINGS_WITHIN_HOLD", "DAILY")
    if f["price"] <= f["sma50"] or f["sma50_slope"] <= 0:
        return reject("DAILY_TREND_DOWN", "DAILY")
    if f["rs_spy_5d"] <= 0:
        return reject("NEGATIVE_RELATIVE_STRENGTH", "DAILY")
    if f["dollar_volume"] < RESEARCH_MIN_DOLLAR_VOLUME:
        return reject("LOW_LIQUIDITY", "DAILY")
    if f["extension_atr"] > RESEARCH_MAX_EXTENSION_ATR:
        out = reject("EXTENDED_FROM_EMA20", "DAILY")
        out["status"] = "WAIT"
        return out
    return {"status": "CANDIDATE", "phase": "DAILY", "features": f,
            "reasons": ["DAILY_REGIME_UP", "RS_OUTPERFORMS_SPY"],
            "blockers": [], "asof": f.get("asof")}
```
