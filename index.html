Cara menyimpan perubahan

Halaman ini statis, jadi perubahan watchlist dikirim ke GitHub dan diproses GitHub Actions. Dua cara, dua-duanya gratis:

1. Lewat issue (default). Tombol tambah/hapus membuka issue GitHub yang sudah terisi — kamu tinggal klik Create. Tanpa token, tanpa rahasia tersimpan di browser.

2. Lewat token (1 klik). Tempel fine-grained token di bawah dan perubahan langsung tersimpan tanpa membuka tab baru.

Buat token di Settings → Developer settings → Fine-grained tokens, batasi ke repo stock-dashboard saja, beri izin Contents: Read and write. Token disimpan di localStorage browser ini saja dan hanya dikirim ke api.github.com — tidak pernah masuk ke repo. Siapa pun yang memakai browser ini bisa membacanya, jadi jangan pakai di perangkat bersama.
